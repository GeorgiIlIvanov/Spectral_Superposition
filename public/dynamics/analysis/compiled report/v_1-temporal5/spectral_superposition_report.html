1. Experimental Setup

This report documents a large-scale parameter sweep for the Toy Models of Superposition experiment, studying how neural networks learn to represent more features than they have dimensions (superposition). The key observable is the emergence of quantized "ray structure" in the fractional dimensionality vs feature norm phase space.

1.1 Model Architecture

Model: ReLU output autoencoder

The model implements the transformation:

h = W @ x     (Projection: ℝn → ℝm)
x' = ReLU(WT @ h + b)     (Reconstruction: ℝm → ℝn)
Loss = MSE(x, x')

Input distribution: x_i = 0 with probability S (sparsity), else x_i ~ Uniform(0,1)

2. Phase Stratification and Spectral Analysis

2.1 Phase Diagram

The central observable in this study is the relationship between the fractional dimensionality Di and the squared feature norm ||Wi||² in the phase space.

Fractional Dimensionality:

Di = (Mii)² / (M²)ii

where M = WTW is the Gram matrix.

Figure 2.1: Phase diagram showing the relationship between fractional dimensionality Di and feature norm ||Wi||². Features cluster along distinct rays, with the slope corresponding to inverse eigenvalues of the frame operator S = WWT.

2.2 Slope-Eigenvalue Correlation

Key Conjecture: The linear slope of each ray corresponds to the inverse eigenvalue 1/λ of the corresponding eigenspace of the frame operator S = WWT.

Figure 2.2: Correlation between cluster slopes κ and eigenvalues λ. For λ > 1, the relationship κ ≈ 1/λ holds with high accuracy (R² = 0.94, Pearson r = 0.97).
Figure 2.3: Summary of the slope-eigenvalue relationship showing the breakdown of spectral interpretation for λ < 1.

2.3 The Dark Matter Regime

Dark Matter Features: For eigenvalues λ < 1, where the majority of features lie and clusters are larger, the spectral interpretation breaks down. We call this regime the "dark matter" of superposition.

Characteristics:

  • 73-84% of features have R² < 0.9 for the Di vs ||Wi||² linear fit
  • Lower eigenspace concentration (spread across multiple eigenspaces)
  • Higher eigenspace entropy
  • Negative curvature in their Di(t) vs ||Wi(t)||² trajectories

To understand the underlying dynamics of this dark matter regime, we conducted two large-scale analysis experiments: Dynamic Hopping Analysis and Temporal Dynamics Analysis.

3. Dynamic Hopping Analysis

Goal: Quantify and visualize "dynamic hopping" of features during training via time-variation of the Rayleigh quotient.

3.1 Mathematical Foundation

The Rayleigh Quotient

For a weight matrix W(t) ∈ ℝd×n at checkpoint t, the Rayleigh quotient for feature i is:

κi(t) = (wi(t)T S(t) wi(t)) / ||wi(t)||²

where S(t) = W(t) W(t)T is the feature covariance matrix.

Simplified Computation

Since S = W WT, we can simplify:

κi = ||WT wi||² / ||wi||² = Σj (wjT wi)² / ||wi||²

This measures how much feature i "overlaps" with all other features relative to its own magnitude.

Derived Quantities

Symbol Definition Interpretation
ai(t) ||wi(t)||² Squared L2 norm of feature i
κi(t) Rayleigh quotient Feature's participation in covariance structure
xi(t) log(κi(t) + ε) Log-transformed quotient (numerical stability)
Di(t) ai(t) / κi(t) Related to effective dimension

Jump Detection

A "jump" indicates sudden change in feature behavior, detected using robust statistics:

  1. Compute differences: Δxi(t) = xi(t) - xi(t-1)
  2. Robust standard deviation using Median Absolute Deviation (MAD):
    σrobust = 1.4826 × median(|Δx - median(Δx)|)
  3. Jump threshold: A jump occurs when |Δxi(t)| > z × σrobust (z = 4.0 by default)

4. Temporal Dynamics Analysis

Goal: Investigate whether "dark matter" features (those with poor Di ~ ||Wi||² linear scaling) are transient states during training that eventually stabilize into clean eigenspaces, or represent a persistent structural phenomenon.

Key Question: Is the dark matter a transient phenomenon (features "in transit" between eigenspaces during training) or a persistent structural feature of superposition?

4.1 Dark Matter Evolution

Analysis 1: Track the fraction of dark matter features (R² < 0.9 for Di vs ||Wi||²) as a function of training step.

Metrics computed at each checkpoint t:

  • For each feature i, compute R² of Di(τ) vs ||Wi(τ)||² for τ ∈ [0, t] (cumulative)
  • Count features with R² < 0.9 (dark matter) vs R² ≥ 0.9 (well-behaved)
  • Track feature transitions between categories
Figure 4.1: Dark matter evolution showing: (Top) Cumulative and windowed dark matter fraction over training by sparsity bucket; (Bottom) Feature transition statistics and rates.

4.2 Eigenspace Stability

Analysis 2: Track how features migrate between eigenspace clusters during training.

Key Metrics:

  • Eigenspace assignment: Dominant eigenspace for each feature at each checkpoint
  • Hopping rate: H(t) = fraction of features that changed eigenspace at step t
  • Stabilization time: First checkpoint after which a feature never hops again
  • Correlation: Between hopping frequency and final R² (dark matter status)
Figure 4.2: Eigenspace stability analysis showing: hopping rate over training, total hops vs concentration, eigenvalue regime comparison (λ>1 vs λ≤1), and hop-R² correlation by sparsity.

4.3 Instantaneous Linearity

Analysis 3: Compare linear fit quality using different temporal windows to determine if poor R² is due to slope changes during training or intrinsic nonlinearity.

Two approaches:

  1. Cumulative R²: Fit Di vs ||Wi||² using all checkpoints [0, t]
  2. Instantaneous slope: Local slope dDi/d||Wi||² at each checkpoint using sliding window

Key questions:

  • Does instantaneous slope converge to a stable value?
  • Is the poor R² due to slope changes during training, or intrinsic nonlinearity?
Figure 4.3: Instantaneous vs cumulative linearity: R² by slope stability category, convergence metrics, sample feature slope trajectories, and phase space trajectories.

4.4 Slope-Eigenvalue Temporal Relationship

Analysis 4: Track how well the κ ≈ 1/λ conjecture holds at each checkpoint.

Metrics at each checkpoint:

  • Compute cluster slopes κk(t) for each eigenspace cluster
  • Compute corresponding eigenvalues λk(t)
  • Test correlation κk(t) × λk(t) ≈ 1 at each t
  • Identify eigenvalue regimes (λ > 1 vs λ < 1) where the conjecture holds/fails over time
Figure 4.4: Temporal evolution of κλ relationship: mean κλ over training by sparsity, regime comparison (λ>1 vs λ≤1), κλ distribution evolution, and final κλ by sparsity regime.

config_loader.py - Configuration Loader

#!/usr/bin/env python3
"""Configuration loader for Dynamic Hopping Analysis."""

from pathlib import Path

def load_config() -> dict:
    """Load configuration from 00_config.py"""
    from importlib import import_module
    import sys
    import importlib.util

    module_dir = Path(__file__).parent
    spec = importlib.util.spec_from_file_location("config", module_dir / "00_config.py")
    config_module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(config_module)

    return {
        'epsilon': config_module.EPSILON,
        'epsilon_mad': config_module.EPSILON_MAD,
        'z_threshold': config_module.Z_THRESHOLD,
        'late_window_fraction': config_module.LATE_WINDOW_FRACTION,
        'min_valid_points': config_module.MIN_VALID_POINTS,
        'sparsity_buckets': config_module.SPARSITY_BUCKETS,
        'base_dir': config_module.BASE_DIR,
        'input_dir': config_module.INPUT_DIR,
        'output_dir': config_module.OUTPUT_DIR,
        'plots_dir': config_module.PLOTS_DIR,
        'results_dir': config_module.RESULTS_DIR,
        'feature_block_size': config_module.FEATURE_BLOCK_SIZE,
        'files_per_gpu': config_module.FILES_PER_GPU,
        'local_window_size': config_module.LOCAL_WINDOW_SIZE,
        'smoothing_window': config_module.SMOOTHING_WINDOW,
        'hopping_categories': config_module.HOPPING_CATEGORIES,
    }

def get_sparsity_bucket(sparsity: float, buckets: dict) -> str:
    """Get the sparsity bucket for a given sparsity value."""
    for bucket_name, (low, high) in buckets.items():
        if low <= sparsity < high:
            return bucket_name
    return 'unknown'
